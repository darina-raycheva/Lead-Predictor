# LeadPredictor

Foundation branch for the LeadPredictor dashboard recreation.

## Run locally

Open `index.html` in a browser. No build tooling is required for this HTML/CSS/JS foundation.

## Branch plan

- `main`: foundation and dashboard shell
- `feature/form-controls`: campaign form behavior
- `feature/chart`: interactive forecast chart
- `feature/metrics`: calculated summary cards
- `feature/polish`: responsive and visual refinement
